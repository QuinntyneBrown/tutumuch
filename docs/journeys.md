# User Journeys

Ordered by value to the user, highest first.

| Name | Description | Effort (days) |
|---|---|---|
| Set up the workspace | Developer clones the repo, runs one command and gets a building, testable backend solution and Angular workspace with the empty application shell (prerequisite for every other journey) | 3 |
| Browse catalog | Anyone browses active listings | 3 |
| View listing detail | See photos, description, price and seller | 4 |
| Checkout and pay | Buyer purchases a listing and pays securely | 7 |
| Create listing | Seller lists an item for girls (audience-locked) for sale | 4 |
| Owner sells alone in launch Phases 1 and 2 | The owner, signed in as an administrator, lists every item with the existing sell and edit screens while members only shop; Phase 1 has one flat catalog of fewer than 40 items, Phase 2 adds the category menus, Phase 3 opens selling to every member (`L1-021`) | 4 |
| Upload listing photos | Seller adds and orders listing photos | 6 |
| Ship order | Seller marks order shipped with tracking | 4 |
| Seller payouts | Seller receives earnings from completed orders | 5 |
| Search and filter catalog | Narrow listings by keyword, category, brand, condition, price | 5 |
| Complete order | Buyer confirms receipt, order closes | 3 |
| Send email notifications | Members get emails for key order events | 4 |
| Resolve order problems | Buyer raises issue, admin resolves it | 5 |
| Cancel order | Buyer or seller cancels before shipping | 4 |
| Order history | Members view past purchases and sales | 3 |
| Manage my listings | Seller sees all their listings in one place | 3 |
| Edit and withdraw listing | Seller updates or removes a listing | 4 |
| View member profile | See a member's public profile and listings | 3 |
| Manage notification preferences | Member chooses which notifications they receive | 3 |
| Manage cookie consent | Visitor accepts or rejects optional cookies | 3 |
| Sign in with Google | Visitor joins or signs in with their Google account | 6 |
| Request items | Member asks for an item that is not in the closet yet (category, keywords, highest price, lowest condition), manages their requests on My requests and is emailed when a matching listing is published or relisted (`L1-023`) | 6 |
| Request a showcase item | The owner marks one of their listings as a showcase; Buy now on it shows Sold and "Request this item" instead of checkout, a visitor signs in or joins and comes straight back to the request, a member sends a short note, and the owner sees every request in the admin shell (`L1-024`) | 4 |
