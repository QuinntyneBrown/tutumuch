Foundation

Motion

Quick and ease-out: 150, 200 and 250ms on cubic-bezier(0.23, 1, 0.32, 1). Only what helps moves; nothing animates on page load.

WCAG 2.2 AAStatus: stablePage guidelines
  • Overview
  • Durations
  • Usage
  • Reduced motion
  • Tokens

Overview

Motion follows the page guidelines (section 10). Use CSS transitions with the motion tokens: --duration-fast 150ms (hover and colour), --duration-base 200ms (reveals, menus, toasts), --duration-slow 250ms (dialogs, sheets, drawers), all on --ease-out = cubic-bezier(0.23, 1, 0.32, 1). --ease-standard, --ease-enter and --ease-spring alias it: no bouncing UI (the logo already bounces).

Durations

Usage

  • Animate only what helps: a sheet or dialog opening, a toast arriving, a button changing colour on hover.
  • No page-load entrance animations on sections, no fades on scroll, no bouncing or wiggling UI, no skeleton shimmer.
  • Never transition: all; name the properties (background-color, color, box-shadow, translate, opacity).
  • Nothing over 250ms except status loops (--duration-spin, --duration-loop).
.btn {
  transition:
    background-color var(--duration-fast) var(--ease-out),
    color var(--duration-fast) var(--ease-out),
    box-shadow var(--duration-fast) var(--ease-out);
}

Reduced motion

Under prefers-reduced-motion: reduce the tokens set the durations to 0.01ms, so every transition built on them stops. The in-place spinner keeps its slow turn because it reports status. The Angular root also disables animations through @.disabled (L2-065).
