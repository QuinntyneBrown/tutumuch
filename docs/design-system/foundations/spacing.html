Spacing

A 4px scale. Small gaps inside components, big gaps between sections, so related things visibly belong together.

WCAG 2.2 AAStatus: stableGiddy design system
  • Overview
  • Scale
  • Usage
  • Tokens

Overview

Components use --space-1–--space-6 inside; layouts use --space-6 and up between groups. Never invent a value.

Usage

  • Field parts 4px; fields 16px; card padding 24px; sections 32–48px.
  • Chip and button gaps 8–12px.
  • Dialogs: 24px padding, 16px between header, body and footer.
  • Listing grid: 16px column gap and 32px row gap on phones, 24px and 40px from 768px.
