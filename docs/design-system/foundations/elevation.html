Elevation

Four shadow levels and a z-order scale.

WCAG 2.2 AAStatus: stableSince v0.1
  • Overview
  • Shadows
  • Z-order
  • Usage
  • Tokens

Overview

Surfaces step from canvas to surface to raised. Shadows are subtle in light and heavier in dark, where the shadow colour becomes pure black.

Usage

Cards use level 1, menus level 3, dialogs and sheets level 4. Dark theme keeps the same levels; surfaces also lighten one step so elevation stays readable.
