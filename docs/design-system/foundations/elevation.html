Foundation · Giddy

Elevation

Four soft shadows, a chunky press lip for primary buttons, and a fixed z-order.

WCAG 2.2 AAStatus: stableGiddy design system
  • Overview
  • Shadows
  • Z-order
  • Both themes
  • Usage
  • Tokens

Overview

Cards sit at level 1, raised items at 2, menus at 3, dialogs at 4. The press shadow is a solid 4px lip under primary buttons that makes them feel squishy and tappable. In dark mode shadows are darker and surfaces lighter as they rise.

Usage

  • Never set a raw z-index.
  • Only primary buttons use the press lip; it disappears while pressed, disabled or busy.
  • Photo stamps (Reserved, Sold) use level 1 so they lift off the photo well.
