Foundation · Giddy

Layout

Mobile-first grid with 4/8/12 columns from Giddy’s layout tokens, inside TuTuMuch’s top-bar shell and the L2-061 breakpoints.

WCAG 2.2 AAStatus: stableGiddy design system
  • Overview
  • Breakpoints
  • Live grid
  • Page templates
  • Usage
  • Tokens

Overview

Base styles are for 360px. Giddy’s grid tokens go to 8 columns with 24px gutters and 32px margins at 768px, and to 12 columns with 32px gutters and 48px margins at 1024px. TuTuMuch keeps its marketplace page layout: component media queries use the L2-061 breakpoints (576, 768, 992 and 1200px), so the top bar, catalog filters and listing detail change at 768px and 992px. There is no sidebar or bottom tab bar.

Breakpoints

NameL2-061 width (media queries)Grid tokensShell
xs0–5754 columns, 16 gutter, 16 marginMenu button, logo, search icon; dialogs are bottom sheets

md7688 columns, 24, 32Primary nav and Sell in the top bar; 3-column listing grid
lg99212 columns from 1024, 32, 48Search field, filters sidebar, 4-column grid, inline buy bar
xl120012 columns, 32, 48Container max 1280px

The --layout-breakpoint-* tokens hold Giddy’s values (640, 768, 1024, 1280, 1536px) for reference; CSS media queries cannot read custom properties, so TuTuMuch writes the L2-061 values in rem.

Page templates

  • App shell: skip link, top bar, main#main.container.page, footer, toast region.
  • Auth shell: large logo above a centred 26rem card.
  • Admin shell: top bar with the Admin tag and no footer.
  • Bare shell: logo-only top bar for maintenance and offline pages.
  • Forms: .page--form 44rem column; narrow pages 40rem.

Usage

  • Containers cap at --layout-container-max (1280px) and pad with --layout-margin.
  • Grid children set min-width: 0; long words wrap so no page scrolls horizontally at 320px.
  • Breakpoints are written in rem in media queries (custom properties can’t be used there).
