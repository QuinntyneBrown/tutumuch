Foundation

Layout

Breakpoints from L2-061, a fluid grid with gutters and margins that grow with the viewport.

WCAG 2.2 AAStatus: stableSince v0.1
  • Overview
  • Columns, gutters and margins
  • Page templates
  • Usage

Overview

Tutu Much is mobile first. The breakpoints are the five of L2-061: extra small below 576px, small from 576px (--layout-breakpoint-sm, 36rem), medium from 768px (48rem), large from 992px (62rem) and extra large from 1200px (75rem).

Page templates

  • App shell: skip link, top bar, main#main.container.page, footer, toast region.
  • Auth shell: large logo above a centred card.
  • Admin shell: top bar with the Admin tag and no footer.
  • Bare shell: logo-only top bar for maintenance and offline pages.

Usage

  • Containers cap at --layout-container-max (1280px) and pad with --layout-margin.
  • Grid children set min-width: 0; long words wrap so no page scrolls horizontally at 320px.
