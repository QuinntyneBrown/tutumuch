Foundation

Typography

Fraunces for headings and prices, DM Sans for everything else, Titan One only in the logo. Sentence case, no letterspaced capitals, self-hosted OFL fonts.

WCAG 2.2 AAStatus: stablePage guidelines

Overview

Type follows the page guidelines (section 4) and the brand kit’s type scale (ADR general/0009). Fraunces (--font-family-display, semibold, tight tracking, the kit’s soft axis SOFT 100) gives headings and prices a storybook warmth. DM Sans (--font-family-sans, the default) is clean and easy to scan for body, buttons, labels and forms. Titan One (--font-family-logo) is used only by tl-logo and tl-mark, never for headings or UI.

--font-size-h1 and --font-size-body grow at 48rem (768px), so the H1 goes from 36px to 48px and body from 16px to 18px.

Usage

  • One <h1> per page. Never skip heading levels.
  • Sentence case everywhere: “Shop soccer gear”, not “Shop Soccer Gear”.
  • No all-caps letterspaced labels above headings. --letter-spacing-wide is 0 and --text-overline is sentence case.
  • No emoji.
  • Body text about 70 characters per line (--layout-measure).
  • Prices and numbers in tables use tabular figures.
  • Never retype “TuTuMuch” in a font to fake the logo; use tl-logo.

Self-hosted fonts

Fraunces, DM Sans and Titan One are self-hosted under the SIL Open Font License, so no font is fetched from a third party:

  • fraunces-latin-full.woff2: Fontsource 5.3.0, latin, variable axes opsz, wght, SOFT and WONK.
  • dm-sans-latin-opsz.woff2: latin, variable opsz and wght.
  • Titan One, with Fraunces-OFL.txt and DMSans-OFL.txt.

The app serves them from src/frontend/projects/tutumuch/public/fonts/; copies live in docs/mocks/assets/fonts/ and docs/design-system/assets/fonts/, declared in a fonts.css beside each with font-display: swap. Variable files keep the kit’s soft axis and optical sizing.

Accessibility

  • All sizes in rem, so they follow the browser font size.
  • Body line height 28px; text-spacing overrides (WCAG 1.4.12) clip nothing.
  • Weight is never the only signal of state.
  • Muted text is used only at sizes and on backgrounds that keep 4.5:1.
