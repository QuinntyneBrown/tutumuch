Typography

Archivo-style black display headings over Inter body text, with role shorthands.

WCAG 2.2 AAStatus: stableSince v0.1
  • Overview
  • Scale
  • Usage
  • Accessibility
  • Tokens

Overview

Headings use --font-family-display at black weight with tight tracking, echoing the heavy numerals of the logo. Body text uses --font-family-sans at 16px with a 1.5 line height. The mocks load no web fonts; the stacks fall back to the system sans.

Scale

Display 48

--text-display

Heading 1 36

--text-h1

Heading 2 30

--text-h2

Heading 3 24

--text-h3

Body 16 — Everything in your size.

--text-body

Body small 14

--text-body-sm

Caption 12

--text-caption

Usage

  • Prose is capped at --layout-measure (65ch).
  • Below 576px h1 drops to 30px and display to 36px.
  • All-caps labels use --text-overline with --letter-spacing-wide.

Accessibility

Body text is 16px minimum and scales with the user's font size because every size is in rem. Line height is 1.5 for body and 1.2 or less for display sizes only.
