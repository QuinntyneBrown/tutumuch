Accessibility

WCAG 2.2 AA is the floor for every component.

WCAG 2.2 AAStatus: stableSince v0.1
  • Overview
  • Commitments
  • Testing procedure
  • Tokens

Overview

Every component page documents its role, keyboard map, focus behaviour, labelling, contrast pairs, motion and touch size. Automated checks (axe in CI, L2-064) back the manual commitments below.

Commitments

  • Text contrast 4.5:1, UI edges and focus rings 3:1, in both themes.
  • One shared focus ring on :focus-visible.
  • Dialogs and sheets trap focus and return it on close.
  • Every form field has a visible label; errors are linked by aria-describedby and announced.
  • Live regions for toasts; role="alert" only for danger.
  • Reduced motion removes all animation.
  • Targets 44px below 992px, 24px minimum anywhere.

Testing procedure

Tab through every page; run axe in light and dark; zoom to 200%; check 320px reflow; read with a screen reader once per feature.
