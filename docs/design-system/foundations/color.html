Color

TuTuMuch’s palette — Raspberry, Lilac, Blush, Sunny, Cream and Plum — on Giddy’s colour structure, with a plum night dark theme. Every text pairing passes WCAG 2.2 AA in both themes.

Overview

TuTuMuch uses the Giddy design system’s colour structure (primitives, semantic roles, status, pops, both themes) with its own six named colours: Raspberry (primary: logo and buttons), Lilac (secondary accents), Blush (soft surfaces and tags), Sunny (highlights and deals), Cream (the page) and Plum (text and dark surfaces). Colour has three jobs: brand (the primary button, the current page and the size tag), meaning (info, success, warning, danger) and joy (the pops behind listing photos). Pops are decorative and always paired with words; status colours carry meaning and always come with an icon and text.

  • Light: cream-50 canvas, white surfaces, raspberry-600 accent with white text, raspberry-700 links, plum-800 text.
  • Dark: plum-950 canvas, plum-900 surfaces, plum-850 raised, raspberry-400 accent with plum-950 text on it, raspberry-300 links.
  • Never write a colour in a component; use a semantic token.

Named colours

Six named colours make up the TuTuMuch palette. Each is a step of a full scale (below), and the semantic tokens point at them; components never use them directly. Values are read live from tokens.css.

Raspberry · --palette-raspberry-600Primary: the logo, primary buttons, the size tag, the current page. Raspberry text and links use raspberry-700 so they reach 4.5:1 on cream.
Lilac · --palette-lilac-500Secondary accents and fills (the grape pop). Too light for text; lilac text uses lilac-700 to -800.
Blush · --palette-raspberry-100Soft surfaces and tags: selected rows, subtle accent fills, the pink pop.
Sunny · --palette-sunny-400Highlights and deals; Giddy’s sun pop points at it. Plum text on it, never white.
Cream · --palette-cream-50The page canvas; cream-100 and -200 for wells, hover fills and hairlines.
Plum · --palette-plum-800Text, the inverse toast and, darker, the dark-theme surfaces.

TuTuMuch layout tokens

TuTuMuch keeps its original marketplace layout and components, so a few component styles still name older layout tokens. Each one is an alias of a Giddy token at the end of tokens.css; Giddy stays the only source of the look. New code uses the Giddy names.

  • --palette-ink-* → plum, --palette-paper-* → cream, --palette-stone-* → gray, --palette-signal-* → raspberry (resolved values below).
  • --color-brand → --color-accent.
  • --photo-bg-1 … -6 → pink, mint, sun, sky, grape and orange pop tints.
  • --color-inverse-*: status icons and edges on the inverse toast.

Usage

  • One accent per view: the primary button and the current nav item. The size tag is the only other raspberry.
  • Pops are decoration; pair them with text. Photo wells never carry meaning.
  • New brand theme: add [data-theme="name"] overriding semantic tokens only, then extend contrast-pairs.json and rerun the checker.
