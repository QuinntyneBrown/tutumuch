Color

Ink, paper and one signal red, with status colours and a dark theme built from roles.

Overview

The palette comes from the Tutu Much logo: ink --palette-ink-950, paper --palette-paper-100 and signal red --palette-signal-500. Components never read a primitive; they read semantic roles (--color-*) which each theme remaps.

Usage

  • Signal red is the brand mark, the current-page bar and the size-tag flag. It is never body text and never an error colour.
  • Primary actions are solid ink in light and solid paper in dark; both pairs exceed 7:1.
  • Status colours always pair a background with its own foreground token.
