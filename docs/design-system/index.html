How to use

  1. Link tokens/tokens.css then assets/components.css.
  2. Use the documented classes and attributes; never restyle a component locally.
  3. Consume tokens/tokens.json (DTCG) for native or design tooling.
  4. In the Angular workspace the components library owns these styles under projects/components/src/styles/.

Provenance

TuTuMuch uses the Giddy design system’s structure (token tiers, semantic roles, component anatomy) drawn to the TuTuMuch page guidelines, as mapped onto the Angular workspace and the tl-* components by ADR general/0009. The palette, fonts and type scale come from the TuTuMuch brand kit: Raspberry, Lilac, Blush, Sunny, Cream, Ink and Muted; Fraunces, DM Sans and Titan One (logo only), self-hosted. No gradients, no decorative shapes, no card shadows and no press lip. Components keep TuTuMuch’s marketplace layout. Extracted from docs/mocks on 2026-10-25 and redrawn to the page guidelines on 2026-10-27, which added the mark, Tilly, the condition badge and the skeleton and retired the decorative shapes.
