How to use

  1. Link tokens/tokens.css then assets/components.css.
  2. Use the documented classes and attributes; never restyle a component locally.
  3. Consume tokens/tokens.json (DTCG) for native or design tooling.
  4. In the Angular workspace the components library owns these styles under projects/components/src/styles/.

Provenance

TuTuMuch uses the Giddy design system: its tokens for type, space, shape, elevation and motion, its colour structure and its component look (pill buttons with a press lip, soft corners, rounded display type), with TuTuMuch’s own palette — Raspberry, Lilac, Blush, Sunny, Cream and Plum — layered on top in tokens.css. Components and pages keep TuTuMuch’s marketplace layout. Extracted from docs/mocks on 2026-10-25. The shell components (skip link, top bar, footer, toast, sheet, button, link, form field) are documented first because the application shell is the first feature built; the remaining catalogue components will be added when their screens are implemented.
