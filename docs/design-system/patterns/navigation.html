Navigation

Overview

How a visitor moves around Tutu Much: the top bar's primary navigation from 768px, the navigation sheet below it, the account subnav for members, and the footer.

When to use which

NeedUse
Reach a categoryTop bar nav (md+) or the sheet (below md)
Reach account pagesAvatar link, then the account subnav
Legal and cookie settingsFooter
Bypass the top barSkip link

States

Guest and member top bars; the current category carries aria-current; the sheet is open or absent.

Responsive

Below 768px the primary nav lives in the sheet; from 768px it is in the bar; from 992px the search field is always visible.

Accessibility

Landmarks: banner, navigation (Primary, Footer, Account), search, main, contentinfo. The skip link is first; route changes move focus to the page heading and announce the title.

Content

Category names are single nouns; account tabs are Overview, Listings, Purchases, Sales, Payouts, Profile, Emails, Settings.
