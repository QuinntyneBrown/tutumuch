Spinner

An indeterminate spinner with a status message read by screen readers.

Overview

tl-spinner shows that a short check is running, such as opening a verification link. The message is in a role="status" region; the spinner itself is hidden from assistive technology.

Anatomy

  1. SpinnerAnimated ring, aria-hidden
  2. MessageMuted text, role=status
