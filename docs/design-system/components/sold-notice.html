Sold notice

Tells a shopper an item has already found a home and offers one way forward.

WCAG 2.2 AAStatus: stableSince v0.4

Overview

tl-sold-notice takes the buy bar's place when "Buy now" is chosen on a showcase listing (L2-108). It reuses the Sold label of the sold state (page guidelines 9) so the item reads as sold without leaving the page, and it carries one action, "Request this item".

Anatomy

  1. Sold label (.photo__stamp--sold, static)
  2. Heading, focusable with tabindex="-1"
  3. One line of muted text
  4. Actions: one primary button or link

Variants

Sold

This one has already found a home

We can look for another one like it. Tell us what you’re after.

Default: first time.
Sold

This one has already found a home

You asked for this on Oct 24. Add a note or change it any time.

Already requested.

Sizes

One size; it fills the info column.

States

Static once shown. The action's own states come from Button.

Responsive behaviour

Full width of the info column at every width; below 992 px it sits where the sticky buy bar was, in the flow, so nothing covers the description.

Theming

Sunken surface and the default border in both themes; the Sold label is ink on cream in light and inverts in dark.

Accessibility

role="status" announces it politely; the owner calls focus() so focus moves to the heading after "Buy now" removes the button that had it. The action is a real button or link with a verb label.

Content

Heading: "This one has already found a home". Never "Out of stock" or "Unavailable".

Do and don't

  • Do keep the gallery, price and details visible around it.
  • Don't show it for an ordinary Sold listing: that keeps the Sold stamp and "Find similar".

Tokens

--color-bg-surface-sunken, --color-border-default, --radius-lg, --space-3, --space-5, --text-h4, --color-fg-muted.

Code

<tl-sold-notice #notice heading="This one has already found a home">
  We can look for another one like it. Tell us what you’re after.
  <button actions tlButton="primary" size="lg" type="button" (click)="request()">Request this item</button>
</tl-sold-notice>
