Earnings

The seller's estimated earnings after the platform fee, shown under the price before publishing.

WCAG 2.2 AAStatus: stableSince v0.2

Overview

tl-earnings shows “You earn after the {fee}% fee” and the amount the page computes, (price + shipping) × (1 − fee ÷ 100) rounded to the cent, or a dash while the price is empty or invalid (L2-031). It is display only; the payout feature computes the fee that counts.

Anatomy

  1. LabelNames the fee percentage from TuTuMuch API
  2. Amount--text-label, tabular figures; — when unknown

Responsive behaviour

Label and amount sit on one line and wrap below 320px.

Theming

Subtle background panel; amount in the default foreground.

Accessibility

Role and pattern

A paragraph with aria-live="polite" so the new amount is read after typing.

Keyboard

No keyboard interaction of its own.

Focus

Not focusable.

Labelling

The label carries the fee so the amount is never read alone.

Contrast

Label on subtle

Motion

No motion beyond the shared transitions; removed under reduced motion.

Touch

Interactive parts meet the 44px target.

Content

  • Always name the fee: “You earn after the 10% fee”.
  • Show a dash, never $0.00, while the price is not valid.
