Size tag

Overview

tl-size-tag is the visual signature of TuTuMuch: every listing is for girls, whatever the category, so every tag reads “Girls”. It appears on listing photos and in the fixed size of the sell form.

Anatomy

  1. PillAccent fill, full radius
  2. Label“Girls” in bold overline type

Variants

Girls Girls
One variant: Girls, in every category.

Sizes

Girls Girls
Default and large.

States

Girls
Static.

Responsive behaviour

Fixed size; never wraps.

Theming

--color-fg-on-accent on --color-accent: white on raspberry in light, plum on light raspberry in dark.

Accessibility

Role and pattern

Text with aria-label="Size: Girls’".

Keyboard

No keyboard interaction of its own.

Focus

Not focusable.

Labelling

The aria-label reads the whole size.

Contrast

Tag text on the accent

Motion

No motion beyond the shared transitions; removed under reduced motion.

Touch

Interactive parts meet the 44px target.

Content

  • The only label is “Girls”; the long form “Girls’” is for the fixed size and aria-label.
