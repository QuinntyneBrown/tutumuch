Footer

Small logo, four links and the copyright line at the end of every app-shell page.

Overview

The footer closes the app shell. It carries the legal links and the Cookie settings entry (privacy subsystem), a link-styled button that emits cookieSettings, because it opens a dialog rather than a page. The admin shell has no footer.

Anatomy

  1. LogoSmall variant linking home
  2. Linksnav named Footer: Marketplace rules, Privacy, Terms links and the Cookie settings button
  3. Copyright© {year} TuTuMuch from the clock

Responsive behaviour

Flex row that wraps; below 576px the logo, links and copyright stack with --space-4 gaps. Links wrap with --space-6 horizontal gaps.

Theming

Muted text on canvas with a default top border.

Accessibility

Role and pattern

<footer> (contentinfo) with a nav named Footer.

Keyboard

KeyAction
TabLogo, then each link and the Cookie settings button in order; Enter or Space on the button opens the dialog.

Focus

Shared ring.

Labelling

Link text is the name; the logo link is named TuTuMuch home.

Contrast

Footer text on canvas

Motion

None.

Touch

Links are inline text with 24px line boxes and 24px gaps; the whole row is not a target.

Content

Exactly: Marketplace rules · Privacy · Terms · Cookie settings · © 2026 TuTuMuch.
