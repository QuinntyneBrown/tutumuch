Order timeline

The four steps of an order, Paid, Shipped, Delivered and Completed, with the date each was reached.

WCAG 2.2 AAStatus: stableSince v0.6

Overview

tl-order-timeline shows where an order is (L2-032). Steps before the current one are done, the current step is marked, and later steps have no date. The buyer’s order page and the seller’s sale page both use it.

Anatomy

  1. An ordered list labelled "Order progress"
  2. Per step: a 3px bar, the step name in label type and the date in caption type

Variants

  1. PaidThu 22 Oct
  2. Shipped
  3. Delivered
  4. Completed
  1. PaidSat 24 Oct
  2. ShippedSun 25 Oct
  3. Delivered
  4. Completed
Paid, then Shipped.

Sizes

One size. Four equal columns at every width.

States

done (data-done, default-colour bar), current (aria-current="step", brand bar), to come (border-colour bar, muted text, no date).

Responsive behaviour

The four columns shrink with the page; names and dates wrap inside their column on a phone.

Theming

--color-fg-default, --color-brand, --color-border-default and --color-fg-muted per theme.

Accessibility

An <ol> with aria-label="Order progress"; the current step carries aria-current="step", so the position is not given by colour alone.

Content

Step names are fixed. Dates read "Sat 24 Oct" in UTC.

Do and don’t

  • Do date steps from the order’s status history.
  • Don’t show Cancelled or Refunded as steps; those pages explain the ending in an alert instead.

Tokens

--color-fg-default, --color-brand, --color-border-default, --color-fg-muted, --space-2, --text-label, --text-caption.

Code

<tl-order-timeline [steps]="[{ label: 'Paid', date: 'Sat 24 Oct' }, { label: 'Shipped', date: null }, ...]" />

The current step is the last one with a date. Source: src/frontend/projects/components/src/lib/order-timeline/.
