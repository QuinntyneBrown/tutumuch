Photo uploader

Add, reorder and remove listing photos: a tile per photo, the cover badge, rejected and uploading tiles and the add tile.

Overview

Every listing shows 1 to 8 photos of the actual item (L2-015, L2-017). tl-photo-uploader sits in the Photos section of the listing form. The host uploads each chosen file as soon as it is picked and owns the tiles; the component draws them and reports chosen files, removals and moves. The first photo is the cover.

Anatomy

  1. Photo tileSquare crop of the 400 px thumbnail, focusable, draggable
  2. Cover badgeOn the first tile only
  3. Remove buttonIcon button, “Remove photo n”
  4. Add tileCamera, “Add photos”, “n of 8”, hidden file input
  5. Help and errorLinked to the input by aria-describedby

Responsive behaviour

Three tiles per row below 36rem with an 8px gap, four from 36rem with a 12px gap. Tiles stay square; the add tile has the same size as a photo.

Theming

Tiles use the photo backgrounds; the add tile uses the strong border and muted text, the rejected tile the danger background, border and text tokens.

Accessibility

Role and pattern

A list of tiles followed by a labelled native file input. Each photo tile is a list item named “Photo n of m” (“, cover” on the first).

Keyboard

Tab reaches each photo tile, its remove button and the file input. On a focused photo tile, Left and Right arrow move it one place; focus follows the tile.

Focus

Visible focus ring on tiles and buttons; after a keyboard move focus stays on the moved tile.

Labelling

Remove buttons are named “Remove photo n” or “Remove {file name}”. The input is described by the help text and, when invalid, the error. A polite live region announces “Photo moved to position n of m.”

Contrast

Rejected text on danger background
Add tile text on canvas

Motion

No motion beyond the spinner, which stops under reduced motion.

Touch

Tiles are at least 96px; remove buttons meet the 44px target with their hit area.

Content

  • Help: “JPEG, PNG or WebP up to 10 MB. Drag to reorder; the first is the cover.”
  • Errors come from TuTuMuch API: “Photos must be 10 MB or smaller”, “Use a JPEG, PNG or WebP photo”, “Photos must be at least 800 pixels on the shortest side”, “Add at least one photo”.
  • Count as “n of 8”.

Code

<tl-photo-uploader
  [tiles]="photos()"
  [max]="8"
  [error]="photoError()"
  (filesSelected)="addPhotos($event)"
  (removed)="removePhoto($event)"
  (moved)="movePhoto($event)"
/>
Input or memberEffect
tilesUploaderTile[]: key, state (uploading, ready, rejected), src, name, size (required)
maxPhoto limit, default 8
errorError text; marks the input invalid
inputIdId of the file input, default photos
filesSelectedEmits the chosen File[]
removedEmits the key of the tile to remove
movedEmits { from, to } among the photos

Implemented as tl-photo-uploader in src/frontend/projects/components/src/lib/photo-uploader/.
