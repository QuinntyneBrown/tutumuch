Component · Data display

Stat

One figure with its label, such as “Paid out” and “Pending” on the payouts page.

WCAG 2.2 AAStatus: stableSince v0.8

Overview

tl-stat shows a muted label above a large tabular figure. Group several in a .stats row, which wraps on narrow screens (L2-031).

Anatomy

  1. Label in label type, muted
  2. Value in heading type with tabular figures

Variants

Paid out$33.30
Pending$40.50
In a .stats row the value uses h3 type.

Sizes

One size; the .stats row scales the value down to h3.

States

Static. While loading, the page shows skeleton--text and skeleton--title in place of label and value.

Responsive behaviour

The .stats row wraps; each stat keeps its own width.

Theming

--color-fg-muted for the label and the default foreground for the value in both themes.

Accessibility

Label and value are read in order as text; no role is needed.

Content

Short label in sentence case; money always with cents.

Do and don’t

  • Do keep a row to two to four stats.
  • Don’t put actions inside a stat.

Tokens

--space-1, --space-8, --text-label, --text-h2, --text-h3, --color-fg-muted.

Code

<div class="stats"><tl-stat label="Paid out" value="$33.30" /><tl-stat label="Pending" value="$40.50" /></div>

Source: src/frontend/projects/components/src/lib/stat/.
