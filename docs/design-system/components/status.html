Status

A short status word after a square in its status colour: draft, active, reserved, sold, removed or info.

WCAG 2.2 AAStatus: stableSince v0.10

Overview

tm-status: A short status word after a square in its status colour: draft, active, reserved, sold, removed or info. Added with resolve-order-problems (L2-036).

Anatomy

  1. Square of currentColor
  2. Status word in small type

Variants

Delivered Completed Refunded

Sizes

One size.

States

Static. Tones: draft, active, reserved, sold, removed, info.

Responsive behaviour

Fills its column; text wraps.

Theming

Uses role tokens only, so both themes follow.

Accessibility

The word carries the meaning; colour only repeats it.

Content

One word, the status as the product names it.

Do and don’t

  • Do compose it from @tutumuch/components.
  • Don’t rebuild its markup in a feature library.

Tokens

--color-success-fg, --color-warning-fg, --color-danger-fg, --color-info-fg, --color-fg-muted.

Code

<tm-status tone="removed">Refunded</tm-status>

Source: src/frontend/projects/components/src/lib/status/.
