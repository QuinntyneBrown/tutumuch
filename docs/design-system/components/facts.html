Facts

A definition list of short facts in two columns: muted labels on the left, values on the right. A value can be a status or tabular figures.

WCAG 2.2 AAStatus: stableSince v0.10

Overview

tl-facts: A definition list of short facts in two columns: muted labels on the left, values on the right. A value can be a status or tabular figures. Added with resolve-order-problems (L2-036).

Anatomy

  1. Label (dt) in small muted type
  2. Value (dd), optionally a tl-status or tabular figures

Sizes

Responsive behaviour

Fills its column; text wraps.

Theming

Uses role tokens only, so both themes follow.

Accessibility

A native dl, so each label is announced with its value.

Content

Labels are one or two words in sentence case. Values are short; use “Not yet” rather than leaving one empty.

Do and don’t

  • Do compose it from @tutumuch/components.
  • Don’t rebuild its markup in a feature library.

Tokens

--space-3, --space-8, --text-body-sm, --color-fg-muted.

Code

<tl-facts [facts]="facts()" />
