Center state

A whole-page outcome centred in main: an icon, a heading, a line of text and an actions row.

WCAG 2.2 AAStatus: stableSince v0.2

Overview

Used when a page cannot show its normal content: a blocked action, a limit, a load failure or a finished task. tl-center-state renders the h1, so it is the page's only heading.

Anatomy

  1. Icon.icon--lg in a muted circle
  2. HeadingThe page h1
  3. TextProjected; one or two sentences
  4. ActionsProjected with the actions attribute; primary first

Variants

That’s 20 listings today

You can list more tomorrow. Drafts still save.

Couldn’t open the form

Something went wrong on our side. Ref 5c1d-0e7a

Blocked, limited, error and success (with an item row) share one layout.

Sizes

Not applicable: one size; the block is centred and capped at the reading measure.

States

It’s live

Set up payouts so you’re paid when it sells.

Static; the actions carry their own states.

Responsive behaviour

Actions wrap and stay centred; below 576px they stack full width.

Theming

The icon sits in a quiet circle on the canvas; text uses the default and muted foregrounds. Error states use a raspberry icon (--color-danger-icon), never an all-red screen. A short wait (“Confirming your payment”) shows the mark instead of a spinner, and the “It’s live” confirmation shows Tilly’s show-and-tell pose (Tilly).

Accessibility

Role and pattern

A plain region inside main with the page h1.

Keyboard

No keyboard interaction of its own.

Focus

Focus starts at the top of main after navigation.

Labelling

The heading names the state; the text explains it.

Contrast

Text on canvas

Motion

No motion beyond the shared transitions; removed under reduced motion.

Touch

Interactive parts meet the 44px target.

Content

  • The heading states the situation plainly: “That’s 20 listings today”, “It’s live”.
  • Offer the next step as the one primary action.
  • Errors say what happened and what to do, in plain language.

Code

<tl-center-state icon="clock" heading="That’s 20 listings today">
  <p class="text-muted">You can list more tomorrow. Drafts still save.</p>
  <a actions tlButton="primary" routerLink="/account/listings">Your listings</a>
</tl-center-state>
Input or memberEffect
iconIcon name, shown when there is no code
codeA status code such as "404", shown large in place of the icon
headingThe page h1 (required)
[actions]Projected action buttons and links

Implemented as tl-center-state in src/frontend/projects/components/src/lib/center-state/.
