Listing card

One listing in the catalog grid: cover photo with the size tag, brand, title, condition and price.

WCAG 2.2 AAStatus: stableSince v0.3

Overview

tl-listing-grid lays out tl-listing-cards in 2 columns below 768 px, 3 from 768 px and 4 from 992 px (L2-061). The whole card is one link to the listing.

Anatomy

  1. Photo: a <picture> with a WebP source and a JPEG fallback, explicit width and height
  2. Reserved stamp (optional)
  3. Size tag
  4. Brand (overline)
  5. Title (one line, ellipsis)
  6. Condition and price

Variants

Girls
Janie and JackPink tulle tutu skirtUsed - Excellent$85
ReservedGirls
Janie and JackPink tulle tutu skirtUsed - Excellent$85
Active and Reserved.

Sizes

The card fills its grid column. The photo sizes attribute is (min-width: 1200px) 270px, (min-width: 992px) 23vw, (min-width: 768px) 31vw, 50vw, so a 375 px phone loads the 400 w version (L2-059).

States

Loading: the grid shows 8 skeleton cards with aria-busy="true" and the label "Loading listings". Hover zooms the photo; focus shows the ring around the link.

Responsive behaviour

Columns change at 48rem and 62rem. The first 4 cards load eagerly with high fetch priority; the rest are lazy.

Theming

Photo background and text follow the colour tokens; the Reserved stamp is a surface-coloured pill, Sold is inverse.

Accessibility

The grid is a ul role="list". The link's name is the photo's alt text ("Photo 1 of {brand} {title}") followed by the visible text. All text is bound as text, never HTML.

Content

Prices are whole dollars without cents ("$85"), cents only when non-zero ("$18.50"), with thousands separators.

Do and don't

  • Do give every image its stored width and height.
  • Don't add actions inside the card; it is one link.

Tokens

--photo-bg-*, --space-3, --text-overline, --text-body, --shadow-1.

Code

<tl-listing-grid [cards]="cards" [loading]="loading" />

Source: src/frontend/projects/components/src/lib/listing-card/ and listing-grid/.
