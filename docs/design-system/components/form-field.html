Form field

A visible label, a control, optional help and an error line, wired together for screen readers.

WCAG 2.2 AAStatus: stableSince v0.1

Overview

Every input, select and textarea sits in a .field with a visible <label for>. Help and error text are linked through aria-describedby; an invalid control carries aria-invalid. Forms use one column below 576px.

Anatomy

  1. Label--text-label, for= the control
  2. Control.input, .select or .textarea
  3. Help--text-body-sm muted, id referenced by aria-describedby
  4. ErrorDanger text with a warning glyph

Variants

Input, textarea, select; optional fields say so in the label.

Sizes

--control-height-sm/md/lg.

States

Default, hover, focus, invalid, disabled, read only.

Responsive behaviour

Fields fill their column. .form-row places two fields side by side from 576px and stacks them below (L2-063). inputmode is passed through so phones show the right keyboard.

Theming

Surface background with a strong border; invalid uses the danger solid colour; disabled uses subtle background and disabled text.

Accessibility

Role and pattern

Native labelled controls. Error summaries at the top of a form use role="alert" and link to each invalid field (L2-065 AC5).

Keyboard

KeyAction
TabControl to control; help and error are read with the control.
EnterSubmits the form.

Focus

Ring with zero offset on the control border.

Labelling

Visible label always; placeholder is never the label. Optional fields say "(optional)".

Motion

Border colour over --duration-fast.

Touch

Controls are 40px tall (44px large) and full width on phones.

Content

  • Labels are nouns in sentence case: Email, Password, Price.
  • Help says what to enter or why: "We only email about your orders."
  • Errors say what is wrong and how to fix it: "TuTuMuch accepts only girls' clothing in Dresses".

Code

<div class="field">
  <label class="field__label" for="email">Email</label>
  <input class="input" id="email" name="email" type="email" aria-describedby="email-help">
  <span class="field__help" id="email-help">We only email about your orders.</span>
</div>
Class / attributeEffect
.fieldLabel, control, help, error stack.
.field__label .optionalOptional marker.
.input .select .textareaControls; --sm and --lg sizes.
aria-invalid="true"Invalid border.
.field__errorError line, referenced by aria-describedby.

Angular

<tl-form-field #title fieldId="title" label="Title" [error]="errors().title" [counter]="titleCount()">
  <input class="input" id="title" formControlName="title"
    [attr.aria-describedby]="title.describedBy()" [attr.aria-invalid]="title.invalid()" />
</tl-form-field>

tl-form-field renders the label, help, error and counter around the projected control; the control binds describedBy() and invalid() through the template reference.
