Choice

A checkbox with its label to the right and an optional error line.

WCAG 2.2 AAStatus: stableSince v0.2

Overview

Used for confirmations a member must tick: age, terms, the size label. tl-choice wraps the native checkbox the form binds, so keyboard and forms behaviour stay native.

Anatomy

  1. BoxNative checkbox, accent colour when ticked
  2. LabelClickable; may contain links
  3. ErrorBelow, referenced by aria-describedby

Variants

Plain label, label with links.

Sizes

Not applicable: one size; the box is 20px inside a 44px tall target.

States

Confirm you have read the marketplace rules
Unticked, ticked, invalid.

Responsive behaviour

Labels wrap beside the box at every width.

Theming

Box uses the strong border; ticked uses the accent; invalid uses the danger solid colour.

Accessibility

Role and pattern

Native <input type="checkbox"> inside its <label>.

Keyboard

KeyAction
SpaceToggles the box.

Focus

Shared focus ring on the box.

Labelling

The whole label is the name.

Contrast

Label on canvas
Error on canvas

Motion

No motion beyond the shared transitions; removed under reduced motion.

Touch

Interactive parts meet the 44px target.

Content

  • Write the label as the statement being confirmed: “I have read the marketplace rules”.

Do and don't

Tokens

TokenLightDark
--color-accent
--color-border-strong

Code

<tl-choice #confirm inputId="confirm" [error]="errors().confirm">
  <input type="checkbox" id="confirm" formControlName="confirm"
    [attr.aria-describedby]="confirm.describedBy()" [attr.aria-invalid]="confirm.invalid()" />
  {{ confirmText() }}
</tl-choice>
Input or memberEffect
inputIdId of the projected checkbox (required)
errorError text; shows the error line
describedBy() / invalid()Bind onto the checkbox

Implemented as tl-choice in src/frontend/projects/components/src/lib/choice/.
