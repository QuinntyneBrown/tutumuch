Consent banner

The non-blocking panel that asks a first-time visitor about optional cookies (L2-056).

WCAG 2.2 AAStatus: stableSince v0.10

Overview

tl-consent-banner is fixed to the bottom of the viewport on the inverse surface. It names the choice, offers "Accept analytics" and "Necessary only", and a "Cookie settings" button that opens the dialog. It does not block the page and does not trap focus. The owner (tl-cookie-consent in @tutumuch/privacy) shows it until a choice is saved; the saved confirmation is a success toast.

Anatomy

  1. Headingh2 "Cookies", labels the section
  2. TextOne sentence, small
  3. ActionsPrimary "Accept analytics", secondary "Necessary only"
  4. SettingsLink-styled button "Cookie settings"

Variants

Not applicable: one banner.

Sizes

One size: full width less 16px insets on phones, 26rem wide from 768px.

States

Cookies

We use necessary cookies to run TuTuMuch. Analytics only if you say yes.

Shown until a choice is saved, then removed. Buttons take the shared hover and an inverse focus ring.

Both themes

Cookies

We use necessary cookies to run TuTuMuch. Analytics only if you say yes.

Cookies

We use necessary cookies to run TuTuMuch. Analytics only if you say yes.

Responsive behaviour

Below 768px it spans the viewport with 16px insets at the bottom; from 768px it is 26rem wide at the bottom right with 24px insets. The actions wrap on narrow screens.

Theming

Inverse surface (--color-bg-inverse, --color-fg-inverse) like the toast; buttons are restyled for the inverse surface, the primary one filled with the inverse foreground.

Accessibility

Role and pattern

section labelled by its heading, so it is a named region "Cookies". Not a dialog: no focus trap, no inert page.

Keyboard

KeyAction
TabReaches the banner after the page content, in source order.
Enter / SpaceActivates a button.

Focus

Focus ring in --color-fg-inverse.

Contrast

Text on inverse

Motion

Slides up on entry; reduced motion removes it.

Touch

Buttons are 44px high.

Content

Exactly: "Cookies" · "We use necessary cookies to run TuTuMuch. Analytics only if you say yes." · Accept analytics · Necessary only · Cookie settings.

Do and don't

  • Do give "Necessary only" the same size as "Accept analytics".
  • Don't block the page or load anything optional while the banner shows.

Tokens

--color-bg-inverse, --color-fg-inverse, --color-border-inverse, --shadow-4, --z-toast, --space-4, --space-6, --text-h4, --duration-slow, --ease-enter.

Code

<tl-consent-banner (accepted)="accept()" (declined)="decline()" (settings)="settings.open()" />
