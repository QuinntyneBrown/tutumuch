Link

Overview

Links go somewhere; buttons do something. Inline links are underlined raspberry; navigation links (.nav-link) are label-weight text with a hover fill and an accent bar when current; footer links are muted and underline on hover.

Anatomy

  2. Underline1px, 2px on hover

Responsive behaviour

Nav links live in the top bar from 768px and in the sheet below it. Inline links wrap with their text.

Theming

--color-fg-link is raspberry-700 in light and a lighter raspberry in dark; the current bar is --color-brand in both.

Accessibility

Native <a href>. aria-current="page" marks the current nav link.
