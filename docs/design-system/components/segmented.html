Segmented control

A radio group drawn as joined segments, inside a fieldset with a visible legend.

WCAG 2.2 AAStatus: stableSince v0.2

Overview

tm-segmented offers a short list of exclusive options, such as the 5 conditions of L2-016, as a form control. Options come from Tutu Much API; option n has the id {groupId}-n, so an error summary can link to the first.

Anatomy

  1. LegendNames the group
  2. SegmentsNative radios with their labels
  3. ErrorBelow the segments

Variants

Nothing chosen yet.

Sizes

Not applicable: one size; segments wrap onto new lines on narrow screens.

Condition

Responsive behaviour

Segments wrap; each stays at least 44px tall.

Theming

Chosen segment uses the accent; invalid uses the danger border.

Accessibility
