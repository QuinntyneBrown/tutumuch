Empty state

An empty or failed region inside a page: icon, heading, text and actions.

WCAG 2.2 AAStatus: stableSince v0.3

Overview

tl-empty-state replaces a list that has nothing to show or could not load. Unlike Center state it sits inside a page section and uses an h2.

Anatomy

  1. Icon
  2. Heading (h2)
  3. Text (projected)
  4. Actions (projected with the actions attribute)

Variants

Nothing listed yet

Be the first to list a pair of 12s or something in L.

Sell an item
Default tone.

Couldn’t load items

Something went wrong on our side. Ref 7f3a-91c2

Error tone, compact, with the reference.

Sizes

One size; the error tone is compact, and [compact]="true" makes any tone compact for an empty section inside a page, such as "No items for sale" on a profile.

States

Static.

Responsive behaviour

Centred; actions wrap.

Theming

The error icon uses the danger colour tokens.

Accessibility

The heading is an h2 under the page h1. The error text carries the correlation reference as text.

Content

Say what happened and the next step in one short sentence.

Do and don't

  • Do offer one primary action.
  • Don't use it for a whole-page block; use Center state.

Tokens

--space-*, --color-fg-muted, danger tokens.

Code

<tl-empty-state icon="tag" heading="Nothing listed yet">…<a actions tlButton="primary">Sell an item</a></tl-empty-state>

Source: src/frontend/projects/components/src/lib/empty-state/.
