Empty state

Tilly waving hello, one short line and one action, for a list with nothing to show.

WCAG 2.2 AAStatus: stable

Overview

tl-empty-state replaces a list that has nothing to show or could not load. By default it shows Tilly’s “Hello, friend” pose ([tilly]="true"). The error tone, and screens that already show Tilly (a category header), use the icon well instead, so a screen never has two Tillys. Unlike Center state it sits inside a page section and uses an h2.

Anatomy

  1. TillyThe hello pose, --size-illustration-lg, alt “Tilly waving hello from a stack of folded clothes”
  2. Headingh2, one short line
  3. TextOptional, muted
  4. ActionOne button, projected with the actions attribute

Variants

Nothing listed yet

List a dress, a leotard or anything she’s outgrown.

Sell outgrown gear
Default: Tilly.

Couldn’t load items

Something went wrong on our side. Ref 7f3a-91c2

Error tone, compact, with the reference: the raspberry icon well, never Tilly, never an all-red screen.

No items for sale

[tilly]="false": the icon well, for a page that already shows Tilly.

Sizes

One size; [compact]="true" reduces the padding for an empty section inside a page. The error tone is compact.

States

Static. The action keeps its button states.

Responsive behaviour

Centred; the action wraps under the text. Tilly keeps her ratio.

Theming

Text tokens follow the theme; Tilly’s artwork never changes. The error icon uses --color-danger-bg and --color-danger-icon (raspberry).

Accessibility

The heading is an h2 under the page h1. Tilly has her alt text; the icon is aria-hidden. The error text carries the correlation reference as text.

Text on canvas
Error icon on its well

Content

  • One short line and one action: “The closet is empty for now” → Sell outgrown gear; “No results” → Clear filters.
  • Errors say what happened and what to do, in plain language.
  • No exclamation points except in Tilly’s voice, at most one per page.

Do and don't

  • Don’t show Tilly in the empty state when the page header already shows her.
  • Don’t use it for a whole-page block; use Center state.
