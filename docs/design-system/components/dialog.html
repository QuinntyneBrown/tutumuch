Dialog

A modal panel over a dimmed page, opened through DialogService, with a title, description, optional alert, body and footer.

WCAG 2.2 AAStatus: stableSince v0.2

Overview

Dialogs ask one question or offer one action without leaving the page. DialogService.open(Component, data) appends the component to body, makes the rest of the page inert, moves focus to the element marked data-autofocus, closes on Escape and returns focus to the opener. The component composes its markup from tm-dialog and closes itself through DialogRef.

Anatomy

  1. IconOptional, info or danger tone
  2. Titleh2, names the dialog (aria-labelledby)
  3. DescriptionProjected [description] (aria-describedby)
  4. TopProjected [top] alerts
  5. FooterProjected [footer] actions, primary last

Set it with the size input: <tm-dialog heading="Got it and all good?" size="sm">. On phones every size fills the width less the page margins.

Responsive behaviour

Below 576px the panel is a bottom sheet with rounded top corners; from 576px it is centred.

Theming

Raised surface over the backdrop token; shadow 4.

Accessibility

Role and pattern

role="dialog" with aria-modal="true"; the page behind is inert.

Keyboard

KeyAction
TabMoves within the dialog; the page behind is inert.
EscapeCloses and returns focus to the opener.

Focus

Moves to the data-autofocus element, else the first control; back to the opener on close.

Labelling

Title by aria-labelledby, description by aria-describedby; the close button is labelled Close.

Contrast

Text on raised surface

Motion

No motion beyond the shared transitions; removed under reduced motion.

Touch

Interactive parts meet the 44px target.

Content

  • Title is the question or task: “Verify your email first”.
  • Footer actions are verbs; the dismiss action says Not now or Cancel.

Code

this.dialogs.open(VerifyEmailPromptComponent, { email });

<tm-dialog heading="Verify your email first" icon="mail">
  <span description>Open the link we sent to <strong>{{ data.email }}</strong> to buy and sell.</span>
  <ng-container ngProjectAs="[footer]">
    <button tmButton type="button" (click)="ref.close()">Not now</button>
    <button tmButton="primary" type="button" data-autofocus (click)="resend()">Resend link</button>
  </ng-container>
</tm-dialog>
Input or memberEffect
DialogService.open(component, data)Returns a DialogRef
DialogRef.close(result?)Closes; closed resolves with the result
DIALOG_DATAInjection token for the data
heading / icon / tone / sizeInputs of tm-dialog; tone is info (default) or danger
