Skip link

The first focusable element on every page; visible only on focus, it jumps past the top bar to #main.

WCAG 2.2 AAStatus: stableSince v0.1

Overview

The skip link lets keyboard and screen-reader users bypass the top bar. It is rendered by the application shell before everything else and targets main#main, which carries tabindex="-1" so focus lands inside the page.

Anatomy

  1. LinkText "Skip to content", href #main
  2. ContainerRaised surface, level-3 shadow, sits at --z-tooltip

Variants

Not applicable: one skip link per page; no variants.

Sizes

Not applicable: one size; padding --space-2 by --space-4.

Responsive behaviour

Same at every width; it sits --space-4 from the top-left when focused.

Theming

Reads --color-bg-surface-raised, --color-fg-default and --shadow-3; themes swap them.

Accessibility

Role and pattern

Native link, first in DOM order (WCAG 2.4.1).

Keyboard

KeyAction
TabReveals the link as the first stop.
EnterMoves focus to #main.

Focus

Off-canvas until :focus-visible; the shared ring applies.

Labelling

The visible text is the name.

Contrast

Text on raised surface
Focus ring on surface

Motion

Slides down over --duration-fast; none under reduced motion.

Touch

At least 44px tall when shown.

Content

Always "Skip to content". Never "Skip navigation".
