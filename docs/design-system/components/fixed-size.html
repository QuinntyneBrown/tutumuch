Fixed size

The size set by the category, shown as read-only text with the size tag. There is never a size input.

WCAG 2.2 AAStatus: stableSince v0.2

Overview

TuTuMuch accepts one size per category (L2-011). Once a category is chosen tl-fixed-size shows the tag, “Size: Girls'” and “Set by category” (L2-012). The server sets the stored size whatever the client sends (L2-013).

Anatomy

  1. Size tagLarge size tag
  2. Size textSize: and the accepted size
  3. CaptionSet by category, subtle

Variants

GirlsSize: Girls'Set by category
GirlsSize: Girls'Set by category
The same in Dresses, Tops, Outerwear and Bottoms.

Sizes

Not applicable: one size; uses the large size tag.

States

GirlsSize: Girls'Set by category
Absent until a category is chosen; updates when it changes.

Responsive behaviour

Tag, text and caption wrap onto two lines below 360px.

Theming

Text on the canvas; the tag keeps its own tokens.

Accessibility

Role and pattern

Plain text; no control, so nothing to operate.

Keyboard

No keyboard interaction of its own.

Focus

Not focusable.

Labelling

The text names the size; the tag has an aria-label.

Contrast

Caption on canvas

Motion

No motion beyond the shared transitions; removed under reduced motion.

Touch

Interactive parts meet the 44px target.

Content

  • Write the long form: “Girls'”.
  • Never offer another size.
