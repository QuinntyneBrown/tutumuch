Icon

One decorative inline SVG from the TuTuMuch icon set, sized with the type.

WCAG 2.2 AAStatus: stableSince v0.2

Overview

tl-icon renders an icon from the set in Iconography with aria-hidden="true". Icons sit beside text that names the action; icon-only buttons carry an aria-label.

Anatomy

  1. Glyph24px viewBox, 1.5 stroke, currentColor
  2. Sizesm, md (1.25em), lg

Variants

info, check-circle, alert, x-circle, mail, clock, check, close, refresh, plus, lock, menu, camera.

Sizes

sm, md, lg.

States

Static; takes the colour of its text.

Responsive behaviour

Scales with the font size of its parent.

Theming

Stroke is currentColor, so it follows the text token.

Accessibility

Role and pattern

Decorative: aria-hidden="true", focusable="false".

Keyboard

No keyboard interaction of its own.

Focus

Never focusable.

Labelling

The surrounding text or aria-label names the action.

Contrast

Icon on canvas

Motion

No motion beyond the shared transitions; removed under reduced motion.

Touch

Interactive parts meet the 44px target.

Content

  • Pair every icon with words unless the control has an aria-label.

Do and don't

Tokens

Sizes are classes, not tokens: .icon--sm (16px), .icon (20px), .icon--lg (24px). Colour is currentColor; status icons use their --color-*-icon token.

TokenLightDark
--color-danger-icon
--color-success-icon
--color-warning-icon
--color-info-icon

Code

<tl-icon name="refresh" />
<tl-icon name="mail" size="lg" />
Input or memberEffect
nameOne of the IconName values (required)
sizesm | md | lg
