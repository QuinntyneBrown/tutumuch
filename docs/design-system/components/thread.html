Thread

Messages in time order, each with who wrote it and when, the text and optional photo thumbnails: the buyer’s claim on an order problem and the seller’s one reply.

WCAG 2.2 AAStatus: stableSince v0.10

Overview

tl-thread: Messages in time order, each with who wrote it and when, the text and optional photo thumbnails: the buyer’s claim on an order problem and the seller’s one reply. Added with resolve-order-problems (L2-036).

Anatomy

  1. Item panel on --color-bg-surface-sunken
  2. Caption: author, optional role and day in caption type
  3. Text in body type
  4. Optional square photo thumbnails in an .uploader list

Variants

You · Sat 24 Oct

Label inside says 11.5, not 12.

vintage_lou · Sun 25 Oct

My mistake, the box said 12. Happy to take them back.

Sizes

One size.

States

Static. A thread always has at least one entry; the seller’s reply is added once it exists.

Responsive behaviour

Fills its column; text wraps.

Theming

Uses role tokens only, so both themes follow.

Accessibility

Plain text in document order, read top to bottom. Each photo has alt text naming whose photo it is and its position.

Content

Captions name the viewer as “You”. On the administrator’s page they add the role: “marcus_12 · buyer · Sun 25 Oct”.

Do and don’t

  • Do compose it from @tutumuch/components.
  • Don’t rebuild its markup in a feature library.

Tokens

--space-1, --space-4, --color-bg-surface-sunken, --text-caption.

Code

<tl-thread [entries]="thread()" />
