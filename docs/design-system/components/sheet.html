Sheet

A full-screen (below 768px) or side (768 to 991px) dialog that slides over the page; the navigation menu and the catalog filters use it.

Overview

The sheet is the mobile answer to menus and filter panels. It is a modal dialog with a heading, a close button that takes initial focus, a scrolling body and an optional footer of actions. The navigation sheet (id="menu") is opened by the top bar's menu button; it closes on navigation and on resize to 768px or wider.

Anatomy

  1. HeadLogo, visually hidden heading, Close menu button
  2. Bodynav with large category links and small account links
  3. FootGuest: Sign in and Join TuTuMuch; member: Sign out

Responsive behaviour

  • Below 768px: full screen, fade in.
  • 768 to 991px: side panel from the left, slide in.
  • 992px and up: the navigation sheet is never shown; filters become a sidebar.

Theming

Canvas background, default borders; the footer buttons follow the button tokens.

Accessibility

Role and pattern

WAI-ARIA dialog (modal): role="dialog", aria-modal="true", aria-labelledby pointing at the hidden heading. Background content is inert.

Keyboard

KeyAction
Tab / Shift+TabCycles inside the sheet (focus trap).
EscCloses and returns focus to the menu button.
Enter on a linkNavigates and closes.

Focus

Initial focus on Close menu; focus returns to the opener on close.

Labelling

Heading "Menu" (visually hidden); Close menu is an icon button with aria-label.

Contrast

Link text on canvas
Primary button label

Motion

Fade or slide over --duration-slow; none under reduced motion.

Touch

Category links are 56px tall; small links 44px; footer buttons 48px.

Content

Categories in the same order as the top bar; then Sell an item, Marketplace rules; guest footer Sign in and Join TuTuMuch.
