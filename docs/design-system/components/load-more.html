Load more

Shows how many items are shown and loads the next page on request.

WCAG 2.2 AAStatus: stableSince v0.3

Overview

tl-load-more sits under a paged list: "Showing {shown} of {total}" and a Load more button.

Anatomy

  1. Count
  2. Button, described by the hidden note "Loads the next 24 items"

Variants

Showing 24 of 1,284
Default.

Sizes

One size.

States

Showing 24 of 1,284
Busy while the next page loads; the button is hidden once everything is shown.

Responsive behaviour

Centred under the grid at every width.

Theming

Uses the Button component.

Accessibility

Focus stays on the button after loading; the page announces the new count in its polite live region.

Content

Numbers use thousands separators.

Do and don't

  • Do keep loaded items when the next page fails, and offer Try again.

Tokens

--space-*.

Code

<tl-load-more [shown]="24" [total]="1284" [busy]="busy" (loadMore)="next()" />

Source: src/frontend/projects/components/src/lib/load-more/.
