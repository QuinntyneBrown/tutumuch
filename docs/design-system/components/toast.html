Toast

Short, transient confirmation in a polite live region at the bottom of the screen.

WCAG 2.2 AAStatus: stableSince v0.1

Overview

Toasts confirm an action without taking focus. The region is role="status" aria-live="polite"; newest toast at the bottom. Non-danger toasts auto-dismiss after 8s with a progress bar and pause on hover and focus; danger toasts carry role="alert" and stay until dismissed.

Anatomy

  1. IconKind icon in the inverse status colour
  2. Title and text--text-label and --text-body-sm
  3. ActionOptional single text button
  4. DismissIcon button named Dismiss
  5. Progress2px bar for auto-dismiss

Responsive behaviour

The region spans the viewport width with 16px insets below 576px and is 24rem wide at the bottom right from 576px.

Theming

Inverse surface (--color-bg-inverse, --color-fg-inverse) so the toast contrasts with the page in both themes; the kind colour uses the --color-inverse-* tokens.

Accessibility

Role and pattern

Region role="status", aria-live="polite"; a danger toast adds role="alert". Focus never moves to a toast.

Keyboard

KeyAction
TabReaches the action and Dismiss buttons in order; hover or focus pauses the timer.
EnterActivates the action or dismisses.

Focus

The ring colour flips to --color-fg-inverse inside the toast.

Labelling

Dismiss is an icon button with aria-label; the action is a text button.

Contrast

Text on inverse
Focus ring in toast

Motion

Slide up on enter, fade on leave; none under reduced motion. Danger toasts do not time out.

Touch

Dismiss is 24px minimum with 16px padding around; the action has a 44px line box.

Content

Title of two to four words in sentence case; optional one-line text; action verbs: View listing, Undo, Try again.

Code

In the application, call ToastService.show({ tone, title, text, action }) from @tutumuch/components; the shell's tl-toast-region renders the toasts, times out all but danger after 8 seconds and pauses on hover and focus. Source: src/frontend/projects/components/src/lib/toast-region/.

<div class="toast-region" role="status" aria-live="polite">
