Find card

One shelf find in a grid: where it is, what it costs and whether TuTuMuch can grab it.

WCAG 2.2 AAStatus: stableSince v0.5

Overview

tl-find-card shows one shelf find on /finds (L2-114, ADR catalog/0009). A find has no photo, so a sunken 4:3 well holds the map pin. It sits in the listing grid (2, 3 or 4 columns, one column under 576 px with .find-grid) and links to /finds/{reference}. It is never mixed with listing cards.

Anatomy

  1. Well: sunken surface, the map-pin icon in the accent, decorative
  2. Title on one line, ellipsis
  3. Category
  4. Store, after a small map pin
  5. “Seen {date}” with a time
  6. Foot: the shelf price and, optionally, the “Grab available” badge (info)

Variants

  • Lilac ballet leotardDanceDancewear CornerSeen Sat 24 Oct$40.00Grab available
  • Light-up glitter sneakersShoesTargetSeen Fri 23 Oct$24.99
With a grab offer, and without (or with a grab already open).

Sizes

One size; it fills its grid cell.

States

Default, hover (title underlined), focus (ring around the whole card), loading (a tl-skeleton well and three lines, inside a container with aria-busy).

Responsive behaviour

One card per row under 576 px (L2-114 AC7), two from 576 px, three from 768 px and four from 992 px, as the listing grid.

Theming

The well uses the sunken surface and the accent for the pin in both themes; text uses the default and muted foregrounds.

Accessibility

The card is one link whose name is its text. The well and both pins are hidden from assistive technology. Text is bound as text, never HTML (L2-049).

Content

The price with cents (“$40.00”), “Seen {weekday} {day} {month}”, and the badge exactly “Grab available”. Never show who asked for a grab (L2-121).

Do and don't

  • Do keep finds on their own page; they are not listings.
  • Don't show “Grab available” when a grab is already open on the find.

Tokens

--color-bg-surface-sunken, --color-accent, --radius-card, --space-0-5, --space-1, --space-2, --space-3, --text-body, --text-body-sm, --color-fg-muted, --font-weight-medium.

Code

<ul class="listing-grid find-grid" role="list">
  @for (find of finds(); track find.reference) {
    <li><tl-find-card [card]="{ href: '/finds/' + find.reference, title: find.title, category: find.category,
      store: find.storeName, seenOn: find.seenOn, seenLabel: 'Seen Sat 24 Oct', price: '$40.00', grabAvailable: find.grabAvailable }" /></li>
  }
</ul>
