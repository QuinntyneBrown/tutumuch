Top bar

The sticky header of the app shell: menu button, logo, primary navigation, search and the account entry for a guest or a member.

WCAG 2.2 AAStatus: stableSince v0.1

Overview

The top bar frames every app-shell page. Sell appears from 768px and the full search field from 992px. The six category links (Clothing, Shoes, Dance, Sports, Cameras and tech, Toys and crafts) need the width of the xl breakpoint, so they show inline only from 1280px; below that the menu button opens the menu sheet that lists them (L2-062). The admin and bare shells use a reduced top bar with the logo only.

Anatomy

  1. Menu buttonaria-label Open menu, aria-controls menu; below xl (1280px) only
  2. LogoLink to / named TuTuMuch home
  3. Primary navnav aria-label Primary; aria-current on the active category
  4. Searchform role search with a visually hidden label
  5. ActionsGuest: Sell, Sign in. Member: Sell, avatar link

Responsive behaviour

  • Below 768px: menu button, logo, search icon button, Sign in. Sell is hidden; it lives in the menu sheet. Nothing scrolls sideways at 320px.
  • From 768px: Sell appears. The menu button stays; the category links live in the menu sheet.
  • From 992px: the search field replaces the search icon button.
  • From 1280px (--layout-breakpoint-xl): the six category links appear inline and the menu button hides.

Theming

Surface background with a default border; the active-link bar uses --color-brand in both themes.

Accessibility

Role and pattern

A <header> (banner landmark) containing a nav named Primary and a form with role="search". The menu button owns the sheet through aria-controls and aria-expanded.

Keyboard

KeyAction
TabMenu, logo, nav links, search, actions in DOM order.
Enter on menuOpens the navigation sheet and moves focus to Close menu.

Focus

The shared focus ring; sticky position keeps focused controls visible.

Labelling

Icon-only controls carry aria-label (Open menu, Search). The avatar link is named "Your account, {name}".

Angular

<tl-top-bar [member]="auth.member()" />

With a member, tl-top-bar shows Sell as a nav link with the plus icon and the avatar link “Your account, {display name}”; without one it shows Sell and Sign in buttons. The application passes the member from AuthState in @tutumuch/api.
