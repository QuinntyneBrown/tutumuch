Top bar

The header of the app shell: the logo on the left, search in the middle, Sell and Account on the right, and the six categories in a second row.

WCAG 2.2 AAStatus: stable

Overview

tl-top-bar follows the page guidelines’ header skeleton. Row one: the menu button (below 768px), the logo, the search field (“Search the closet”), then Sell and Account, or Sell and Sign in for a guest. Row two, from 768px: the six categories in guideline order, Dance · Sports · Clothing · Shoes · Cameras and tech · Toys and crafts. TuTuMuch has no cart, so there is no Bag link or count (ADR general/0009). Launch phases still hide the category row and Sell (L2-093, L2-094, ADR platform/0014). The admin and bare shells use a reduced bar with the logo only.

Anatomy

  1. Menu buttonBelow 768px only; aria-label “Open menu”, aria-controls menu
  2. Logotl-logo [responsive]="true": the wordmark from 640px, tl-mark (36px) below, in one home link named “TuTuMuch home”
  3. Searchform role search, visually hidden label “Search TuTuMuch”, placeholder “Search the closet”
  4. ActionsGuest: Sell, Sign in. Member: Sell (plus icon), avatar link “Your account, {name}”
  5. Category rownav aria-label Primary; from 768px; aria-current on the active category

Logo tone

tl-logo has two tones. The top bar always uses the default tone="color", because the bar is on the surface colour.

ToneWhereDrawing
color (default)White, cream or blush backgrounds: the header, auth pages, marketingPolka-dot “TuTu”, gingham “Much”, ink outline, raspberry shadow
reversedOnly on raspberry backgroundsInk outline, ink shadow (--color-logo-reversed-shadow), paler dots (--color-logo-reversed-dot), a sunny “Much” (--color-logo-reversed-much)

The reversed artwork is drawn by tl-logo itself; never fake it by retyping “TuTuMuch” in Titan One, and never put either tone on a photo, a pattern or lilac.

Logo size

The header wordmark is set at 2.25rem (about 2.9rem tall) and the mark below 640px at 44px, within the 4rem top bar (ADR general/0010).

Sizes

Row one is --layout-topbar-height (64px); the category row adds a 44px line from 768px. Gap --space-3 below 768px, --space-6 from 768px. The logo uses size="md" (28px, never smaller); the mark is 36px. Clear space equal to the height of the “u” stays around the logo.

Responsive behaviour

  • Below 640px: menu button, the mark (inside the home link), search, Sign in or the avatar. Nothing scrolls sideways at 320px.
  • From 640px: the wordmark replaces the mark.
  • From 768px: the category row appears below and the menu button hides; Sell shows in row one.
  • The row and the category nav cap at --layout-container-wide (80rem). Nothing in the bar wraps to two lines at desktop width.

Theming

Surface background with a thin ink/10 bottom line (--color-border-default). The logo and mark keep their own colours in both themes. The active category uses --color-fg-accent.

Accessibility

Role and pattern

A <header> (banner) with a nav named Primary and a form role="search". One logo link per page: under 640px the mark sits inside the same link, so assistive technology meets one “TuTuMuch home”.

Keyboard

KeyAction
TabMenu, logo, search, actions, then the category row.
Enter on menuOpens the navigation sheet and moves focus to Close menu.

Focus

2px raspberry ring with a 2px offset on every control.

Labelling

Icon-only controls carry aria-label (Open menu, Search). The avatar link is named “Your account, {name}”. The logo image and the mark are decorative.

Contrast

Category link on surface

Touch

Every control is at least 44px tall.

Content

  • Categories, in this order: Dance, Sports, Clothing, Shoes, Cameras and tech, Toys and crafts.
  • Search placeholder: “Search the closet”; hidden label “Search TuTuMuch”.
  • Actions: “Sell” and “Sign in”. The Sell link stays “Sell”; longer seller calls to action elsewhere read “Sell outgrown gear”.
  • No Bag: TuTuMuch has no cart. If a bag is ever added, it is called “Bag”.

Do and don't

  • Don’t add a Bag link or count; there is no cart.
  • Don’t repeat the logo in the page body; the footer uses the mark.
