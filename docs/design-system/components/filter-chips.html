Filter chips

A group of toggle chips that picks one value, each with a count, such as the status filter of “Your listings”.

WCAG 2.2 AAStatus: stableSince v0.9

Overview

tl-filter-chips is a role="group" of .chip buttons. Exactly one is pressed; choosing another changes the list below it (L2-021). Unlike Chip, which shows an applied filter with a remove button, these chips are the choices themselves.

Anatomy

  1. Group with an accessible label
  2. Chip button with its label
  3. Count in .num with tabular figures

Variants

All pressed (default).
One status pressed (filtered).

Sizes

One size: --control-height-sm.

States

Rest (surface with a thin ink/15 ring), hover (--color-bg-subtle), focus-visible (2px raspberry ring, 2px offset), and pressed (aria-pressed="true"): lilac at 15% with a lilac ring and ink text. A chip with a count of 0 stays enabled.

Both themes

Responsive behaviour

The .cluster wraps onto more lines on narrow screens; chips keep their width.

Theming

Uses the Chip tokens: --color-selected-bg and --color-selected-border for the pressed chip, --color-border-ring at rest. Both themes follow.

Accessibility

Each chip is a native button with aria-pressed; its name includes the count (“Sold 2”). The group is named by aria-label. Tab moves between chips; Enter or Space presses one.

Content

One word per label in sentence case, “All” first.

Do and don't

  • Do keep the chosen value in the URL so it survives a reload.
  • Don’t allow more than one pressed chip; use the filters sheet instead.
  • Don’t fill the pressed chip with raspberry; selected is lilac.

Catalog filters

The catalog sidebar (and the filters sheet below 992px) shows the three most useful groups first and open: Category, Size (a fixed note, “Every item is in Girls’ sizes.”, since there is one size) and Condition. Brand and Price sit behind a “More filters” disclosure (.filters__more-group).
