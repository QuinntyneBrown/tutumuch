Filter chips

A group of toggle chips that picks one value, each with a count, such as the status filter of “Your listings”.

WCAG 2.2 AAStatus: stableSince v0.9

Overview

tm-filter-chips is a role="group" of .chip buttons. Exactly one is pressed; choosing another changes the list below it (L2-021). Unlike Chip, which shows an applied filter with a remove button, these chips are the choices themselves.

Anatomy

  1. Group with an accessible label
  2. Chip button with its label
  3. Count in .num with tabular figures

Variants

All pressed (default).
One status pressed (filtered).

Sizes

One size: --control-height-sm.

States

Rest, hover (--color-bg-subtle), focus-visible ring, and pressed (aria-pressed="true", accent fill). A chip with a count of 0 stays enabled.

Responsive behaviour

The .cluster wraps onto more lines on narrow screens; chips keep their width.

Theming

Uses the Chip tokens, so light and dark themes follow --color-accent and --color-fg-on-accent.

Accessibility

Each chip is a native button with aria-pressed; its name includes the count (“Sold 2”). The group is named by aria-label. Tab moves between chips; Enter or Space presses one.

Content

One word per label in sentence case, “All” first.

Do and don’t

  • Do keep the chosen value in the URL so it survives a reload.
  • Don’t allow more than one pressed chip; use a sheet of filters instead.

Tokens

--space-8 below the group, plus the Chip tokens.

Code

<tm-filter-chips label="Filter by status" [options]="options" [selected]="'all'" (selectedChange)="filter($event)" />
