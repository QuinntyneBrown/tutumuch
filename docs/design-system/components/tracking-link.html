Tracking link

The carrier and tracking number of a shipped order, linking to the carrier’s tracking page.

WCAG 2.2 AAStatus: stableSince v0.6

Overview

tm-tracking-link shows "USPS tracking" and the number as an external link built by Tutu Much API (L2-033). The buyer’s order page and the seller’s sale page both use it once the order is Shipped.

Anatomy

  1. "{carrier} tracking" label in small muted text
  2. The number in groups of four with tabular figures
  3. External-link icon

Variants

USPS tracking9400 1118 9922 3456 1204 77
One variant per carrier name: USPS, UPS, FedEx, DHL.

Sizes

One size.

States

Link states from Link: default, hover, focus-visible.

Responsive behaviour

Label and number sit on one row and wrap onto two on a narrow phone; the number breaks anywhere rather than overflowing.

Theming

Link colour and --color-border-default rules per theme.

Accessibility

The link opens a new tab with rel="noopener"; a visually hidden "(opens in a new tab)" follows the number. The icon is decorative.

Content

"{carrier} tracking". The number is grouped in fours for reading; the link uses the number as stored.

Do and don’t

  • Do use the URL from Tutu Much API.
  • Don’t build carrier URLs in the browser.

Tokens

--space-1, --space-2, --space-4, --color-border-default.

Code

<tm-tracking-link carrier="USPS" number="9400111899223456120477" [url]="tracking.url" />

Source: src/frontend/projects/components/src/lib/tracking-link/.
