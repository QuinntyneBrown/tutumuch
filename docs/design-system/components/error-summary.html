Error summary

Every problem of a refused form, listed at the top as links to the fields, focused and announced.

WCAG 2.2 AAStatus: stableSince v0.2

Overview

When a submit is refused tl-error-summary lists each problem in field order, takes focus and is announced as an alert (L2-065). Each link moves focus to its control, where the same message shows inline. It renders nothing while the list is empty.

Anatomy

  1. IconDanger
  2. TitleFix these to continue
  3. LinksOne per field, same text as the inline error

Variants

Fix these to continue
  • That display name is taken
  • An account with this email already exists
  • Password must be at least 12 characters
Client and server errors use the same list.

Sizes

Not applicable: one size; fills the form column.

States

Fix these to continue
  • Choose a category
Shown and focused after a refused submit; absent otherwise.

Responsive behaviour

Fills the form column; long messages wrap.

Theming

Danger alert tokens.

Accessibility

Role and pattern

role="alert", tabindex="-1" so it can take focus.

Keyboard

KeyAction
TabMoves through the links.
EnterMoves focus to the field.

Focus

Takes focus whenever a new list is shown.

Labelling

Link text is the field's error message.

Contrast

Link on the danger background

Motion

No motion beyond the shared transitions; removed under reduced motion.

Touch

Interactive parts meet the 44px target.

Content

  • Use the field's own message, word for word.
  • Order the links as the fields appear.
