Chip

An applied filter, shown as a selected chip: lilac at 15% with a lilac ring and ink text, and a remove button.

WCAG 2.2 AAStatus: stableSince v0.4

Overview

tl-chip shows each active catalog filter in the toolbar (“Dance”, “New with tags”, “$20–$200”). Removing it removes that one value. Selected chips are drawn the page-guidelines way: --color-selected-bg (lilac at 15%) with a 1px --color-selected-border ring and ink text. Lilac is never used for text.

Anatomy

  1. Label
  2. Remove button, labelled "Remove filter {label}"

Variants

Dance New with tags $20–$200
Selected (the only variant the catalog uses).

Sizes

One size: --control-height-sm tall.

States

Selected; the remove button shows a hover fill and the 2px raspberry focus ring.

Both themes

Dance New with tags
Dance New with tags

Responsive behaviour

Chips wrap inside the toolbar at every width.

Theming

Light: lilac 15% over cream with a lilac ring and ink text. Dark: lilac 30% over the plum night with a lilac 300 ring and light text.

Accessibility

The remove button names the value it removes. After removal, the polite item count announces the new result.

Content

Use the label the filter shows; prices as "$20–$200", "From $20" or "Up to $200".

Do and don't

  • Do pair chips with a "Clear all" link button.
  • Don't use a chip as a navigation link.
