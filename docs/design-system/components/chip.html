Chip

One applied filter value with a button that removes it.

WCAG 2.2 AAStatus: stableSince v0.4

Overview

tl-chip shows each active catalog filter in the toolbar ("Dresses", "New with tags", "$20–$200"). Removing it removes that one value.

Anatomy

  1. Label
  2. Remove button, labelled "Remove filter {label}"

Variants

Clothing New with tags $20–$200
Selected (the only variant the catalog uses).

Sizes

One size: --control-height-sm tall.

States

Selected; the remove button has hover and focus rings.

Responsive behaviour

Chips wrap inside the toolbar at every width.

Theming

Accent background and on-accent text in light and dark.

Accessibility

The remove button names the value it removes. After removal, the polite item count announces the new result.

Content

Use the label the filter shows; prices as "$20–$200", "From $20" or "Up to $200".

Do and don't

  • Do pair chips with a "Clear all" link button.
  • Don't use a chip as a navigation link.

Tokens

--color-accent, --color-fg-on-accent, --radius-sm, --control-height-sm.

Code

<tl-chip label="Clothing" (remove)="show(without)" />
