Button

Buttons trigger actions. Five variants, three sizes, six states.

Overview

A button performs an action on the current page; a link goes somewhere. Primary is a raspberry pill with a pressable lip, secondary is outlined, ghost is text with a hover fill, link looks like prose, danger is reserved for destructive confirmations. One primary per view.

Anatomy

  1. Leading icon (optional)1.25em, aria-hidden
  2. LabelVerb phrase, sentence case
  3. Container--control-height-*, --radius-md, 1px border

Variants

Emphasis from highest to lowest.

<button class="btn btn--primary" type="button">Primary</button>
<button class="btn" type="button">Secondary</button>
<button class="btn btn--ghost" type="button">Ghost</button>
<button class="btn btn--link" type="button">Link</button>
<button class="btn btn--danger" type="button">Danger</button>
Icon-only buttons carry aria-label; block buttons fill the row.

Responsive behaviour

  • Below 768px the primary action of a form or page header becomes .btn--block.
  • Dialog and sheet footers keep buttons on one row and wrap when needed; the primary stays last.
  • Small buttons appear only inside rows that are themselves targets.

Theming

Four component tokens (--btn-bg, --btn-fg, --btn-border, --btn-bg-hover) alias semantic tokens per variant. In dark the accent becomes a lighter raspberry with a plum label.

Accessibility

Role and pattern

Native <button>; a link styled as a button stays an <a href>.

Keyboard

KeyAction
TabFocus in DOM order.
Enter, SpaceActivate.

Focus

Shared ring with a 2px offset; the gap shows the surface so the ring stays 3:1.

Labelling

The label is the name; icon-only buttons set aria-label. Loading adds aria-busy and keeps the name.

Contrast

Motion

Background transitions over --duration-fast; active translates 1px; both removed under reduced motion.

Touch

Medium and large exceed 44px; small is 32px and only used inside tappable rows.

Content

  • Verb phrases in sentence case: Sign in, Sell, Buy now, Save changes. Never OK, Submit, Click here.
  • Destructive labels name the loss.
  • Three words or fewer where possible.

Angular

<button tlButton="primary" type="submit" [busy]="busy()">Publish</button>
<a tlButton size="lg" [block]="true" routerLink="/sell">Sell an item</a>

The tlButton directive in src/frontend/projects/components/src/lib/button/ sets the classes and aria-busy on a native button or link. Inputs: variant (the directive value: primary, ghost, link, danger or empty), size, block, busy.
