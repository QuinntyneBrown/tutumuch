Quote

A member’s own words in curly quotes with their display name below, such as the seller’s note on a cancelled order or the buyer’s request to cancel.

WCAG 2.2 AAStatus: stableSince v0.9

Overview

tm-quote sets text a member wrote apart from Tutu Much’s own copy: a rule on the left, the text in curly quotes and the display name as the citation (L2-035).

Anatomy

  1. Left rule in --color-border-strong
  2. Text in body type, wrapped in “ and ”
  3. Citation: the display name in small muted type

Variants

“Found a crack in the heel counter while packing. Sorry about this.”

vintage_lou
On a page, or in a dialog body.

Sizes

One size.

States

Static. Leave it out when the member wrote nothing; never show empty quotes.

Responsive behaviour

The text wraps; long words break anywhere.

Theming

--color-border-strong for the rule and --color-fg-muted for the citation in both themes.

Accessibility

A native blockquote with cite; screen readers announce it as a quotation.

Content

Show the text exactly as written, trimmed. The citation is the display name only.

Do and don’t

  • Do use it only for words a member wrote.
  • Don’t quote Tutu Much’s own messages; use an alert.

Tokens

--space-1, --space-4, --text-body-sm, --color-border-strong, --color-fg-muted.

Code

<tm-quote [text]="order.cancellation.note" [cite]="order.sellerDisplayName" />
