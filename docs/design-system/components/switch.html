Switch

An on or off setting that applies when the form is saved, such as each row of the Emails page.

WCAG 2.2 AAStatus: stableSince v0.9

Overview

tl-switch is a native checkbox with role="switch" drawn as a pill track and round thumb. Its accessible name is visually hidden, because the row it sits in shows the title and description (L2-043). With a hint it shows the label and hint itself, beside the switch, as in the Cookie settings dialog (L2-056). A locked setting, such as account security email, is shown checked and disabled.

Anatomy

  1. Track, --color-border-strong off and --color-accent on
  2. Thumb on the surface colour with --shadow-1, moving 1.25rem when on
  3. Visually hidden label naming the setting

Variants

On, off, and locked on.
With a hint: the label and hint are visible and the switch sits at the end of the row.

Sizes

One size: a 2.75 by 1.5rem track inside a 44px target line.

States

Off, on, focus (the shared focus ring), disabled at 50% opacity. While its form saves, the owning page disables the switch.

Responsive behaviour

Fixed size at every width; in a .settings-list row it stays at the end of the row.

Theming

Track and thumb use role tokens, so both themes keep 3:1 contrast against the surface.

Accessibility

Native input type="checkbox" with role="switch": Space toggles it, screen readers announce on or off. The label names what the setting controls; a locked one says so, for example “Order emails, always on”.

Content

Name the thing, not the action: “Review emails”, not “Turn on review emails”.

Do and don’t

  • Do pair a group of switches with one Save button when the change needs the server.
  • Don’t use a switch for a choice between two named options; use a segmented control.

Tokens

--color-border-strong, --color-accent, --color-bg-surface, --shadow-1, --radius-sm, --radius-xs, --duration-base, --target-min.

Code

<tl-switch label="Review emails" [(checked)]="reviews" [disabled]="saving()" />
<tl-switch label="Analytics" hint="Helps us see which pages are slow." [(checked)]="analytics" autofocus />
