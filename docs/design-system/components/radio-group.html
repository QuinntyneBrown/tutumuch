Radio group

A required choice of one option: a fieldset with its legend, one Choice per option and an error line the fieldset references.

WCAG 2.2 AAStatus: stableSince v0.9

Overview

tm-radio-group wraps tm-choice radios in a fieldset so the legend names the group, and shows “Choose a reason” style errors under the options (L2-035).

Anatomy

  1. Legend in label type
  2. Radios, each a Choice
  3. Error line, referenced by the fieldset’s aria-describedby

Variants

Reason
Default: nothing chosen.

Sizes

One size; the options stack with --space-2 between them.

States

ReasonChoose a reason
Invalid: every radio carries aria-invalid and focus moves to the first.

Responsive behaviour

Always one column; labels wrap.

Theming

Inherits Choice and Form field colours, including --color-danger-fg for the error.

Accessibility

The legend names the group; arrow keys move between radios; the error is read with the group through aria-describedby.

Content

Legend is a noun (“Reason”). Options are short, in sentence case, in a meaningful order. The error tells the member what to do.

Do and don’t

  • Do preselect nothing when the choice matters.
  • Don’t use it for more than about six options; use a select.

Tokens

--space-2, --text-label, --color-danger-fg.

Code

<tm-radio-group legend="Reason" [error]="reasonError()">
  <tm-choice inputId="reason-0"><input type="radio" id="reason-0" name="reason" />Item damaged</tm-choice>
</tm-radio-group>
